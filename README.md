## タイヤの STL の作り方

標準タイヤ(`models/tire_l.stl`、`tire_r.stl`)と同じ座標で作ると、原点どおりにそのまま付きます。

- 原点は車軸の中心、車軸は **Y 方向**、上は **Z**、単位は **mm**
- 左タイヤは Y が 0 → +120、右タイヤは Y が 0 → −120 に広がる
- 標準タイヤの外径は 370mm。径の違うタイヤは、小さい方が地面から浮いて表示されます
- 座標が違うときは、画面の「位置の合わせ方」「車軸の向き」で合わせられます

ファイル名に `lf` `rf` `lb` `rb` を含めると、その位置(前左・前右・後左・後右)に付きます。

## 部品の座標(CAD のまま、単位 mm)

| 部品 | 位置 |
| --- | --- |
| starm の取り付け中心 | 本体の四隅 (X, Y) = (±360, ±360)、Z = 68.6 |
| starm の回転軸 | 取り付け中心を通る縦(Z)軸 |
| 車軸の中心 | 取り付け中心の真下 231.5mm |
| 標準タイヤの原点 | 回転軸から外側へ 56mm 内側(モーター軸の端がハブ板に当たる位置) |

`models/` の中身は `base_link.stl`、`starm_l.stl`(左)、`starm_r.stl`(右)、`tire_l.stl`、`tire_r.stl` です。前後は同じ形状なので1つにまとめてあります。
