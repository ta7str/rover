# ローバー走行ビューア

KIT-AURORA のローバー(base_link + starm 4本)に、Fusion で作ったタイヤの STL を付けて、3D で走らせて確認するビューアです。ブラウザだけで動き、サーバーやインストールは要りません。

- 本体(`base_link`)と starm 4本は CAD データのまま固定
- **タイヤの STL だけを差し替え可能**(4輪まとめて、または1輪ずつ)
- **starm を回して向きを変えられます**(前輪で曲がる / 前後逆向き / 4輪同じ向き / その場回転 / 1本ずつ手動)
- 旋回半径や横滑りも計算して表示します

## 公開のしかた(GitHub Pages)

1. このフォルダの中身をそのまま GitHub のリポジトリに置く(`index.html` がリポジトリの一番上に来るように)
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、**Branch** を `main` / `(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

private リポジトリで Pages を使うには、GitHub の有料プランが必要です。

## 自分のパソコンで開く

`index.html` をダブルクリックしても部品を読み込めません。次のどちらかで開いてください。

```
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## タイヤの STL の作り方

標準タイヤ(`models/tire_l.stl`、`tire_r.stl`)と同じ座標で作ると、原点どおりにそのまま付きます。

- 原点は車軸の中心、車軸は **Y 方向**、上は **Z**、単位は **mm**
- 左タイヤは Y が 0 → +120、右タイヤは Y が 0 → −120 に広がる
- 標準タイヤの外径は 370mm。径の違うタイヤは、小さい方が地面から浮いて表示されます
- 座標が違うときは、画面の「位置の合わせ方」「車軸の向き」で合わせられます

ファイル名に `lf` `rf` `lb` `rb` を含めると、その位置(前左・前右・後左・後右)に付きます。

## 部品の座標(CAD のまま、単位 mm)

| 部品 | 位置 |
| --- | --- |
| starm の取り付け中心 | 本体の四隅 (X, Y) = (±360, ±360)、Z = 68.6 |
| starm の回転軸 | 取り付け中心を通る縦(Z)軸 |
| 車軸の中心 | 取り付け中心の真下 231.5mm |
| 標準タイヤの原点 | 回転軸から外側へ 56mm 内側(モーター軸の端がハブ板に当たる位置) |

`models/` の中身は `base_link.stl`、`starm_l.stl`(左)、`starm_r.stl`(右)、`tire_l.stl`、`tire_r.stl` です。前後は同じ形状なので1つにまとめてあります。

## 仕組み

three.js(CDN から読み込み)で STL を表示しています。走行は「タイヤは横に滑らない」という条件から車体の動きを求めており、タイヤの向きが合っていないときは横滑りを警告します。重さやモーターの力は考慮していません。
